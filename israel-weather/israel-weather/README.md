# תחזית ישראל – גרסה שרצה בענן

המערכת נבנתה כך שהיא עצמה נכנסת לאתרים כל 15 דקות, גם כשאף אחד לא פותח אותה:

- **GitHub Actions** מריץ את `scripts/sync.mjs` כל 15 דקות. הסקריפט שואב את הנתונים מהאתרים ובונה את הקובץ `data.json`.
- **GitHub Pages** מפרסם את הדף (`public/index.html`) יחד עם הקובץ.
- הדף קורא את `data.json` כל 2 דקות ומתעדכן לבד. בראש העמוד מופיע "✓ המערכת מסונכרנת" וספירה לאחור לעדכון הבא.

הכול חינם, בתנאי שהמאגר (repository) ציבורי.

## מה נשאב ומאיפה

| מקור | מה | תדירות |
|---|---|---|
| **Open-Meteo** (מודלים מספריים, בהם ECMWF) | תחזית שעתית ל־3 ימים ויומית ל־7 ימים לכל 137 היישובים בדף ולכל 20 התחנות | כל 15 דקות |
| **Mavir** | תחזית ל־10 ימים ל־101 ערים | כל 15 דקות נשאב רבע מהערים, כך שכל עיר מתעדכנת פעם בשעה |
| **השירות המטאורולוגי** | אזהרות ותחזית ארצית (פידי RSS רשמיים) | כל 15 דקות |
| **אתרי חדשות** (ynet, וואלה, מעריב, ישראל היום, mako, סרוגים, כיפה, JDN, בחדרי חרדים, כיכר השבת, i24, מקור ראשון) | רק ידיעות על מזג האוויר, לפי מילות מפתח | פעם בשעה |

ידיעות ומבזקים שעברו עליהם 48 שעות נמחקים אוטומטית. נתון Mavir שלא התעדכן 30 שעות לא מוצג.

## התקנה – פעם אחת, כ־10 דקות

1. **חשבון GitHub:** אם אין לך, צור חשבון חינמי באתר github.com.
2. **מאגר חדש:** לחץ למעלה על ‎+‎ ואז **New repository**. תן שם (למשל `israel-weather`), בחר **Public** ולחץ **Create repository**.
3. **העלאת הקבצים:** בעמוד המאגר לחץ **uploading an existing file** (או Add file ← Upload files). גרור לשם את **התוכן** של התיקייה `israel-weather` (התיקיות `public`, `scripts`, `data` והקבצים), ולחץ **Commit changes**.
   - ⚠️ התיקייה `.github` מוסתרת, ולפעמים היא לא נגררת. אם אחרי ההעלאה אין במאגר תיקייה `.github`, לחץ Add file ← **Create new file**, כתוב בשם הקובץ בדיוק `.github/workflows/sync.yml`, הדבק את התוכן של הקובץ `sync.yml` שבחבילה, ולחץ Commit.
4. **הפעלת האתר:** Settings ← **Pages** ← בשדה Source בחר **GitHub Actions**.
5. **הרצה ראשונה:** לשונית **Actions**. אם מופיעה בקשה להפעיל workflows, אשר אותה. אחר כך בחר "סנכרון תחזית ישראל" ← **Run workflow**.
6. **האתר שלך:** אחרי 2–3 דקות האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/israel-weather/`. מכאן הוא מתעדכן לבד כל 15 דקות.

## כדאי לדעת

- **עיכובים:** GitHub מריץ משימות מתוזמנות "בערך" בזמן. בשעות עומס ריצה יכולה להתעכב בכמה דקות, ולעיתים רחוקות גם להידלג.
- **השבתה אחרי 60 יום:** אם לא נעשה שום שינוי במאגר 60 יום, GitHub משבית את התזמון ושולח על כך מייל. כדי להחזיר אותו, נכנסים ל־Actions ולוחצים **Enable workflow**.
- **סנכרון ידני:** Actions ← "סנכרון תחזית ישראל" ← Run workflow.
- **בדיקת תקלות:** כל ריצה כותבת יומן ב־Actions. שורה שמתחילה ב־"נכשל:" מציינת אתר או פיד שלא ענה. הסקריפט ממשיך בלעדיו ומשאיר את הנתונים הקודמים.
- **הוספה או החלפה של פידי חדשות:** ברשימה `FEEDS` שבקובץ `scripts/sync.mjs`. לא את כל כתובות ה־RSS ברשימה יכולתי לבדוק, כי מכאן אין לי גישה לאתרים האלה. פיד שלא עובד פשוט מדולג, וכדאי לבדוק ביומן של הריצה הראשונה אילו מהם ענו.
- **תנאי שימוש:** חלק מהאתרים אוסרים שאיבה אוטומטית. הסקריפט פונה ל־Mavir בקצב מתון (כל עיר פעם בשעה, עד 4 בקשות במקביל), אבל האחריות לבדוק את תנאי השימוש היא שלך. Open-Meteo חינמי לשימוש לא מסחרי.
- **Weather2day לא נכלל:** מכאן לא הייתה לי גישה לקוד הגולמי של עמודי האתר, ולכן לא יכולתי לכתוב לו שואב אמין. התחזית לפי עיר של Weather2day מבוססת ברובה על המודל האירופי (ECMWF), שנכלל כאן דרך Open-Meteo.
